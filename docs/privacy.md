# プライバシーと権限

Hirari は開発者にデータを送りません。利用状況の収集、広告、アカウント登録はありません。

## データの保存と送信

設定、読書位置、しおり、履歴は端末内に保存します。SMB のパスワードは、Android Keystore の鍵で暗号化して保存します。

データが端末の外に出る経路は、利用者が選ぶ次の操作と Android の自動バックアップです。

- 登録した SMB サーバーから本を読みます。接続先に認証情報と、読むファイルの要求を送ります。
- SAF で選んだクラウドの文書を読みます。通信は、その提供元が扱います。
- ページを別のアプリに共有します。共有先にページの画像を渡します。
- 書き出しや「端末に保存」で、選んだ保存先にファイルを渡します。クラウドの提供元を選ぶと、その提供元が通信を扱います。
- Android の自動バックアップが、設定と本体のデータベースを保存します。端末間の移行も同じ範囲です。

自動バックアップには、場所、読書位置、しおり、履歴などを含みます。SMB のユーザー名とドメインも含みます。SMB のパスワードは含めません。復元後はパスワードを入力し直します。SAF のフォルダの権限も取り直します。

取り込んだ書体とキャッシュは、自動バックアップにも設定の書き出しにも含めません。設定の書き出しと自動バックアップは、含むデータの範囲が異なります。詳しい範囲は [仕様書の 7 章](spec.md#7-永続化とプライバシー)にあります。

## 権限

| 権限 | 使う理由 | 求めるとき |
|---|---|---|
| `INTERNET` | 登録した SMB サーバーに接続するため | インストール時に宣言します |
| `ACCESS_LOCAL_NETWORK` | 登録した LAN 内の SMB サーバーに接続するため | Android 17（API 37）以上で、SMB の接続を試すときや保存するときに求めます。この権限が原因で失敗した一覧を読み直すときも求めます |
| `ACCESS_NETWORK_STATE` | ネットワークの変化を知り、SMB に再接続するため | インストール時に宣言します |
| `FOREGROUND_SERVICE`、`FOREGROUND_SERVICE_DATA_SYNC` | 画面を離れても「端末に保存」を続けるため | インストール時に宣言します |
| `POST_NOTIFICATIONS` | 「端末に保存」の進み具合と結果を知らせるため | Android 13（API 33）以上で、最初の保存を始めるときに求めます。断っても保存は続きます |
| `RECORD_AUDIO` | 「息でめくる」で音量を計るため | 「息でめくる」をオンにしたときだけ求めます |

音量は端末内で計算します。音声は保存せず、送信もしません。

ストレージの権限は求めません。本と保存先は、システムのファイル選択画面（SAF）で利用者が選びます。
