# Hirari

Hirari は、自炊した本（主に漫画）を読む Android アプリです。Android 9（API 28）以上で動きます。端末や SD カードの本は、システムのファイル選択画面（SAF）から開きます。登録した SMB サーバーの本も読めます。

## 読めるもの

- ZIP（cbz）、RAR（cbr）、7z、tar の画像書庫。
- 画像を入れたフォルダと、画像だけの PDF。
- プレーンテキストと青空文庫記法のテキスト。縦書きで読めます。
- JPEG、PNG、WebP、GIF、BMP、HEIF、HEIC、AVIF、JPEG XL の画像。

HEIF と HEIC は端末のデコーダに依存します。AVIF は Android 12（API 31）以上が対象です。端末によって読めないことがあります。アニメーションは先頭のフレームを表示します。RAR 4 の solid 書庫、分割書庫、書庫の中の書庫には対応しません。詳しい条件は [仕様書の 3 章](docs/spec.md#3-対応形式と入力の扱い)にあります。

単ページと見開きを切り替えられます。見開きの組ずらしや、縦の連続スクロールも使えます。読書位置、しおり、履歴を残せます。SMB の本は「端末に保存」で保存先へコピーできます。

## インストール

1. [GitHub Releases](https://github.com/yuu-biz/hirari/releases) から `Hirari-X.Y.Z.apk` をダウンロードします。
2. ブラウザかファイル管理アプリで APK を開きます。
3. Android に求められたら、そのブラウザかファイル管理アプリに「不明なアプリのインストール」を許可します。
4. インストールを終えたら、その許可を戻せます。

配布するのは APK 1 個です。`arm64-v8a`、`armeabi-v7a`、`x86_64` をすべて含みます。Google Play と AAB での配布は行いません。パッケージ名は `io.github.yuubiz.hirari` です。

## 署名を確かめる

Android SDK Build Tools の `apksigner` で、ダウンロードした APK を調べます。`X.Y.Z` は版番号に置き換えます。

```sh
apksigner verify --print-certs Hirari-X.Y.Z.apk
```

署名証明書の SHA-256 が、次の値と一致することを確かめます。APK 自体の SHA-256 は、その版の Release の説明と比べます。証明書の値とは別のものです。

```text
1116351eafe09b6f99bff277b959ec1700e12aed7bd1bfd463c534ba2d574441
```

`keytool` の表記では次の値です。

```text
11:16:35:1E:AF:E0:9B:6F:99:BF:F2:77:B9:59:EC:17:00:E1:2A:ED:7B:D1:BF:D4:63:C5:34:BA:2D:57:44:41
```

## 0.0.1 のデバッグ版から移る

`0.0.1-debug.N` は開発用の鍵で署名されています。1.0 はリリース用の鍵を使うため、上書きでインストールできません。アンインストールの前に、必要な記録を書き出します。

1. 古い版の設定で「書き出し」を開きます。「読書位置、しおり、履歴も含める」を選んで保存します。
2. 古い版をアンインストールします。
3. 1.0 の APK をインストールします。
4. 設定で、保存したファイルを読み込みます。
5. SAF のフォルダを場所として選び直します。SMB のパスワードを入力し直します。
6. 履歴としおりにある各本を、フォルダの一覧から一度開きます。本の索引は書き出しに含まれないため、それまでは「（索引にない本）」と出ます。
7. 使っていた書体を取り込み直します。

書き出しで、場所とその権限は引き継げません。SMB のホスト、ポート、共有名、フォルダは含まれますが、資格情報は含まれません。お気に入り、ピン留め、選んだ表紙、取り込んだ書体、キャッシュも含まれません。必要な項目は登録し直してください。
